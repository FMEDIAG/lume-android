🏷️ Lume

Tasación inteligente de cualquier objeto, desde un sello hasta un inmueble.
Lume es una aplicación que permite obtener tasaciones instantáneas y estimadas de prácticamente cualquier tipo de objeto:
coleccionables, arte, vehículos, joyas, maquinaria, inmuebles y mucho más.

Las valoraciones están impulsadas por modelos de IA y bases públicas de todo el mundo, combinando datos históricos, comparables reales y análisis automatizado.

🚀 Características principales

Tasación universal: funciona con objetos pequeños (sellos, monedas, cartas, figuras) y también con bienes de alto valor (coches, relojes, inmuebles).

IA multimodal: analiza imágenes, descripciones y metadatos para generar una valoración estimada.

Datos globales: utiliza bases públicas internacionales, catálogos, registros y comparables reales.

Resultados instantáneos: la valoración se genera en segundos.

Historial de tasaciones: permite consultar y gestionar tasaciones anteriores.

Interfaz rápida y moderna gracias a Vite + React + Tailwind.

🧠 ¿Cómo funciona?

El usuario sube una imagen, saca fotos y/o describe el objeto.

La IA identifica el tipo de objeto y sus atributos relevantes.

Se consultan bases públicas y comparables globales.

Se genera una tasación estimada, con rango de valor y nivel de confianza.

Se muestra un informe claro y exportable.
