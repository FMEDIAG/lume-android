🏷️ Lume

Tasación inteligente de coleccionables con IA.
Lume permite obtener tasaciones estimadas de monedas, billetes, sellos, cartas, vinilos, libros y memorabilia a partir de fotos.

Las valoraciones se apoyan en modelos de IA y en fuentes públicas, combinando datos de mercado y comparables reales.

🚀 Características principales

Tasación de coleccionables: monedas, billetes, sellos, cartas, vinilos, libros y memorabilia.
IA multimodal: analiza fotos y descripciones para identificar el objeto.
Fuentes públicas: consulta catálogos, tiendas y comparables online.
Resultados rápidos: la tasación se genera en segundos.
Historial de tasaciones: consulta y gestiona tasaciones anteriores.

🧠 ¿Cómo funciona?

1. Subes una o varias fotos del objeto y, si quieres, una descripción.
2. La IA identifica la categoría y los datos relevantes.
3. Se consultan fuentes públicas y comparables.
4. Se genera una tasación estimada, con rango de valor y nivel de confianza.
